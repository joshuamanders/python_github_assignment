# Study Time Tracker
## Description
# Program estimates the amount of hours the user will study in a week. It does this by taking the user's study time for one day and multiplying it by seven.
## How to run
```
python app.py
# or
python3 app.py
```
## Example interaction or output 
```
Enter hours studied today: 2
You are on track to study 14 hours this week.
```
